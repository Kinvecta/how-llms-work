[11:56]
So here's the myth: more linear layers means more power. The intuition is reasonable. Each layer adds parameters, so a stack of them should do more than one. But you just watched two layers collapse into one matrix. Goodfellow's textbook makes the general argument: if a layer is linear, the whole network remains a linear function of its input. To describe anything beyond that, in their words, we must use a nonlinear function. A stack of linear maps is still one linear map. The bend has to come from somewhere else.

[12:27]
That doesn't make linear layers useless. Ours changed the dimension, three to two, and mixed the inputs. That's real work. It just doesn't compound. And one more overstatement to retire: "every layer is a matrix multiply." A hidden layer is an affine map followed by a nonlinearity. And in attention, the step that turns scores into weights is a softmax applied to each row, which is not a matrix product at all. Matrices do the heavy lifting. They don't do all of it.
